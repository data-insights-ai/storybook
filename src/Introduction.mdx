  <Section
    eyebrow="The one API rule"
    title="Only ever text is a prop. Anything that can hold a component is a slot."
    lede="A slot is a named sub-component written as a child — `PanelMeta`, `StageFooter`, `ToastAction`. No prop is typed `ReactNode`; that type is the sign the decision was never made."
  >
    <Rules>
      <Rule>A line that reports a measured value is a slot. A count, a timestamp, a version or a delta arrives sealed or in the mono track, and a string can carry neither.</Rule>
      <Rule>A variant is one union prop, never a family of booleans. `tone` means status on the shared ramp and nothing else; what is not a status gets its own name.</Rule>
      <Rule>Every visible string is a prop, in English. A product passes its own language in from outside.</Rule>
      <Rule>Buttons, fields and tables stay native elements. A headless library is worth adding when a control needs more than that, and not before.</Rule>
    </Rules>
  </Section>

  <Section
    eyebrow="How it stays consistent"
    title="Three token layers, four ramps, and a check that fails."
    lede="Primitive values have no job. Semantic roles say what a thing is for and carry the dark remap. Component slots let one control be restyled without touching the others. A component binds to the second or third layer, never the first."
  >
    <Rules>
      <Rule>Space, radius, type and control height are ramps, not opinions. `Foundations/Scale` draws all of them.</Rule>
      <Rule>`pnpm lint:tokens` fails on a raw pixel, a hex literal in a component, or a component naming a primitive. `pnpm build` runs it first, so drift cannot reach the package.</Rule>
      <Rule>An exception states its reason in a comment the lint reads. A silent exemption is drift; a written one is a decision.</Rule>
      <Rule>Visible text meets AA. Status is a word plus a mark, never colour alone. `pnpm test` fails on an axe violation.</Rule>
    </Rules>
  </Section>
