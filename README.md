# datAInsights design system

`@data-insights-ai/ui`: the datAInsights brand as tokens, React components and example screens, developed in Storybook. The screens are composed examples of a console; they are not a named product.

```bash
pnpm install
pnpm storybook   # http://localhost:4500
pnpm check       # format, lint, typecheck, story tests, build
```

Documentation starts at [`docs/README.md`](docs/README.md). Rules for working in this repository are in [`AGENTS.md`](AGENTS.md); what each release changes is in [`CHANGELOG.md`](CHANGELOG.md).
